Alist播放器-鸿蒙系统首个Alist/Openlist播放器
1.可以用alist和openlist帐号直接登陆，同时可设置默认目录，支持多个添加多个Alist服务器并切换。
2.采用libmpv播放器，支持硬解，支持播放时选集，支持字幕、音轨、章节、速率选择。
3.可以列表/网格/瀑布流模式浏览，目录内有封面会自动显示为目录封面，方便看短剧。
4.支持影视模式，对emby/jellyfin结构目录可直接进入影视界面访问，对剧集类目录也支持影视界面。
5.支持自定义首页，图片标题，项目随心设定。
6.支持本地及调用API索引进行搜索。
7.浏览记录，收藏等方便功能可直接定位目录/文件。
8.支持播放进度记录，可设置从头播放/继续播放/提示选择多种方式播放。
9.支持图片缓存，页面瞬间加载。
10.丰富的功能设置，自行摸索。

p.s.终于完美满足了自己的需求:)
